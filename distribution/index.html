Download selfhost

One command-line tool to manage databases, projects and deployments on selfhost.dev.

Download selfhost

Or install with a command

macOS and Linux:

curl -fsSL https://cli.selfhost.dev/install.sh | sh

Windows, in PowerShell:

irm https://cli.selfhost.dev/install.ps1 | iex

Both installers check a published SHA-256 before they write the binary.

Uninstall

Delete the binary. On Windows, also remove the install directory from your user PATH.
